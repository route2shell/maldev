# Lab Safety Checklist

---

## Before a Lab

| Check | Complete |
|---|---|
| Scope is learner-owned and local-only | |
| VM is isolated or on a host-only network | |
| Pre-lab snapshot exists | |
| Exercise uses benign toy artifacts | |
| Evidence notebook is ready | |
| Cleanup path is understood | |

## During a Lab

| Check | Complete |
|---|---|
| No public targets or production systems | |
| Commands and observations are recorded | |
| Direct observations are separated from inference | |
| Unexpected behavior causes a pause and note, not improvisation | |

## After a Lab

| Check | Complete |
|---|---|
| Test programs stopped | |
| Temporary artifacts removed or documented | |
| Evidence saved outside disposable VM state | |
| Snapshot reverted or new clean baseline documented | |
| Next question recorded | |
