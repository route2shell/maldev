# Module 07 Lab 01 - Implant Architecture, Staging, Profiles, and C2 Design Synthesis

---

> **Lab Objective**
>
> Produce the module checkpoint artifact: local-only beacon simulation architecture with component boundaries, task schema, config model, timing model, and observability review.

## Safety Boundary

| Field | Value |
|---|---|
| Allowed target | Learner-owned isolated VM, benign toy program, local simulation, or worksheet |
| Network | Local-only, host-only, or disconnected |
| Snapshot | Required before beginning |
| Cleanup | Required before checkpoint submission |

## Required Environment

- Windows analysis VM or local worksheet environment appropriate for this module
- clean pre-lab snapshot
- evidence notebook
- module reference cheat sheet
- benign lab artifact or simulated evidence only

## Setup Steps

1. Confirm the safety boundary.
2. Record the VM snapshot name and time.
3. Create an evidence folder for `module-07`.
4. Open the module README and reference cheat sheet.
5. Define the lab question in one sentence.

## Lab Steps

1. Review each lesson practice artifact from this module.
2. Build, run, inspect, or simulate the smallest benign artifact needed for the module synthesis.
3. Build the module synthesis table described in the checkpoint.
4. Capture at least three direct observations or worksheet decisions.
5. Write at least two inferences and the validation step for each.
6. Add a defender or analyst interpretation.
7. Complete cleanup and reset notes.
