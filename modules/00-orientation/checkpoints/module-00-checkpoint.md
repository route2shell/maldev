---

> **Checkpoint Goal**
>
> Prove the course lab is installed, isolated, snapshot-backed, tool-ready, and capable of the build-run-inspect workflow required by Module 01 and beyond.

## Readiness Questions

1. What VM will you use for build and analysis work?
2. What network mode prevents accidental exposure to production networks?
3. Which snapshot should you return to before Module 01 labs?
4. Where will source, builds, screenshots, tool output, and notebooks live?
5. Which tool proves the compiler works?
6. Which tool proves PE inspection works?
7. Which tool proves runtime process inspection works?
8. What cleanup did you perform after the smoke test?
