# Glossary

---

| Term | Working definition |
|---|---|
| Artifact | A file, event, memory state, log entry, screenshot, or note created by an experiment |
| Beacon | A recurring tasking loop in a controlled implant architecture; in this course it is local-only |
| Direct observation | Evidence captured directly from a tool, log, debugger, process view, or file |
| Inference | A conclusion drawn from observations that still needs validation |
| Loader | Code responsible for preparing another component or payload for execution |
| Payload | Executable logic with a defined role, represented as an EXE, DLL, shellcode, or other form |
| PE | Portable Executable, the Windows executable file format |
| Stager | A component that prepares or retrieves a later stage in a controlled design |
| Telemetry | Observable signals collected from processes, files, registry, memory, network, APIs, or events |
| Toy target | A benign lab program designed for observation rather than real-world use |
