# Standard Lab Template

---

> **Lab Objective**
>
> State the exact learning goal.

## Safety Boundary

| Field | Value |
|---|---|
| Allowed target | Learner-owned isolated VM or benign toy program |
| Network | Local-only or isolated |
| Snapshot | Required before lab |
| Cleanup | Required before continuing |

## Required Environment

List tools, VM state, source files, and evidence paths.

## Lab Steps

1. Prepare the snapshot and evidence notebook.
2. Build or prepare the benign lab artifact.
3. Run the artifact only inside the isolated lab, or perform the approved local simulation.
4. Inspect file, process, memory, debugger, telemetry, or architecture state.
5. Capture direct evidence.
6. Write inferences separately.
7. Clean up and reset.
